# 小车上位机 V7.0 - UI 设计原型 V2 说明文档

## 一、设计目标

将现有界面从"功能可用"升级为"专业美观"，在保持原有功能布局的前提下，通过现代化的视觉设计提升用户体验。

## 二、当前界面问题分析

| 问题 | 表现 | 影响 |
|------|------|------|
| 布局拥挤 | Margin 普遍 4-8px，控件紧贴 | 视觉压抑，操作易误触 |
| 层次不清 | BgPrimary/BgSecondary 对比度低 | 界面"糊"在一起，难以区分区域 |
| Tab 样式简陋 | 无选中指示器，样式过时 | 导航感弱，不够现代 |
| 控件缺乏质感 | 按钮扁平无反馈，滑块默认样式 | 交互感差，像未完成的原型 |
| 字体无层级 | 标题/标签/数据字号接近 | 信息优先级不明确 |
| 状态不醒目 | 连接状态、流量计数不突出 | 关键信息难以一眼获取 |

## 三、设计方向

**风格定位**: 深色玻璃拟态 (Dark Glassmorphism) + 工业控制面板

- **深色玻璃拟态**: 使用半透明层级、微妙阴影、发光效果营造科技感
- **工业控制面板**: 数据醒目、状态明确、操作反馈清晰，符合上位机工具属性

## 四、配色系统 V2

### 背景层级 (从深到浅)

| 名称 | 色值 | 用途 |
|------|------|------|
| BgDeep | #0D0D0F | 窗口底层背景 |
| BgPrimary | #141416 | 输入框、内容区底层 |
| BgSecondary | #1E1E22 | 头部、状态栏 |
| BgCard | #252529 | 卡片容器背景 |
| BgElevated | #2D2D32 | 按钮、悬浮元素 |
| BgHover | #35353B | 悬停状态 |

**改进点**: 相比旧版 (#1E1E1E → #28282A)，新层级对比度更大，卡片感更强。

### 强调色 (更饱和、更有科技感)

| 名称 | 色值 | 用途 |
|------|------|------|
| AccentBlue | #4C9AFF | 主按钮、焦点、选中 |
| AccentCyan | #00D4AA | 运动控制、摇杆 |
| AccentGreen | #3DDC84 | 在线状态、接收计数 |
| AccentOrange | #FF9F43 | 姿态数据、警告 |
| AccentRed | #FF6B6B | 危险操作、离线状态 |

**改进点**: 饱和度提升，配合发光效果 (DropShadowEffect) 营造霓虹感。

## 五、布局改进

### 整体结构

```
+-------------------------------------------------------------+
|  [标题]连接配置    [标题]数据收发    [标题]运动控制          |
|  +--------------+  +----------------+  +------------------+ |
|  |  连接卡片    |  |  接收区卡片    |  |  控制卡片        | |
|  |  [TabControl]|  |  [头部]        |  |  [TabControl]    | |
|  |  - 串口      |  |  [内容区]      |  |  - 运动控制      | |
|  |  - 网络      |  |  [状态栏]      |  |  - 批量字串      | |
|  |  - 蓝牙      |  +----------------+  |  - 行走路线      | |
|  +--------------+                      +------------------+ |
|  +--------------+  +----------------+  +------------------+ |
|  | 通用设置卡片 |  |  发送区卡片    |  |  姿态监控卡片    | |
|  +--------------+  +----------------+  +------------------+ |
+-------------------------------------------------------------+
```

### 关键改进点

1. **外边框留白**: Grid Margin 从 0 增加到 20，给界面"呼吸空间"
2. **卡片化分区**: 每个功能模块使用圆角卡片 (CornerRadius=8, Padding=16)
3. **标题栏统一**: 每个面板顶部添加带发光指示器的标题
4. **接收区一体化**: 头部+内容+状态栏整合在一个卡片内，圆角分别处理
5. **姿态数据突出**: 使用大号等宽字体 (20px Bold) + 橙色强调

## 六、控件样式改进

### TabControl
- **旧版**: 灰色背景，无选中指示
- **新版**: 透明背景，选中项底部蓝色下划线 (BorderThickness=0,0,0,2)，悬停背景高亮

### Button
- **旧版**: 4px 圆角，简单颜色变化
- **新版**: 6px 圆角，按下时缩放动画 (ScaleTransform 0.98)，禁用状态明确
- **新增类型**: PrimaryButton (蓝色填充)、SuccessButton (绿色)、DangerButton (红色边框悬停填充)

### TextBox
- **旧版**: 直角，聚焦仅变边框色
- **新版**: 6px 圆角，聚焦时蓝色发光阴影 (DropShadowEffect)

### Slider
- **旧版**: 系统默认样式
- **新版**: 自定义 Thumb，蓝色圆形带发光效果

### CheckBox / RadioButton
- **旧版**: 16px，勾选标记细线
- **新版**: 20px，圆角更大，勾选标记更粗 (2.5px)，选中时填充强调色

## 八、实现建议

### 步骤 1: 引入新主题

在 `App.xaml` 中替换主题引用：

```xml
<Application.Resources>
    <ResourceDictionary Source="Themes/DarkThemeV2.xaml"/>
</Application.Resources>
```

### 步骤 2: 逐步替换布局

建议按以下顺序替换，便于验证：

1. 先替换 `DarkTheme.xaml` 内容（或新建并修改 App.xaml 引用）
2. 验证现有界面在新主题下的表现
3. 逐步将 `MainWindow.xaml` 中的布局替换为新设计

### 步骤 3: 绑定检查

新布局中的绑定路径与旧版一致，但需注意：

- 确认 `DataLabel`、`SectionHeader` 等样式资源名正确
- 检查 `FontMono` 资源名（旧版可能直接使用字符串）

### 步骤 4: 细节微调

根据实际运行效果微调：

- 卡片 Padding/Margin
- 字体大小
- 颜色对比度
- 发光效果强度 (DropShadowEffect Opacity)

## 九、可选增强 (未来迭代)

1. **动画效果**: 按钮点击波纹、页面切换淡入淡出
2. **数据可视化**: 姿态数据使用仪表盘或图表替代纯数字
3. **主题切换**: 支持浅色模式
4. **自定义标题栏**: 移除系统标题栏，使用自定义窗口边框
5. **图标系统**: 引入 Segoe Fluent Icons 或自定义图标字体
